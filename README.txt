ESTUDO DE CASO:
Sistema de Recursos Humanos (Sistema RH)

SGBD UTILIZADO:
SQL Server (SQL Server Express 16.0 RTM)

DESCRICAO:
Sistema de gerenciamento de recursos humanos desenvolvido para
controlar funcionarios, departamentos, cargos, folha de pagamento,
ponto, beneficios e avaliacoes de desempenho. O sistema automatiza
o processamento da folha mensal, registra o historico de alteracoes
salariais e garante a integridade dos dados por meio de triggers,
procedures e functions implementadas diretamente no banco de dados.
